# FDE 网站编辑约定

- 这是通用生态合作网站，目标域名 `fde.qintopia.cn`。保持首页、服务能力、项目案例、合作方式以及独立案例详情的结构。
- 用户希望用 v0 套用模板，可重做视觉和优化表达；正文事实、匿名客户、服务条件、案例顺序与路由保留。详细交接见根目录 `V0.md`。
- 用户确认参考 `https://www.distyl.ai/` 的表达清晰度、结构和风格，最终前端由 v0 完成；当前样式仅为可替换基线。
- 呈现效果优先，允许使用应用服务器。默认构建采用完整 Next.js；保留 `build:static` 作为当前代码的 COS 兼容选项，不把纯静态作为最终方案的硬约束。
- 文案维护在 `content/site.ts` 与 `content/cases.json`，展示组件放在 `components/`，样式集中在 `app/globals.css`。
- 保留 11 个完整案例和四段叙事；不得编造收益数字、客户评价、正式合作认证或验收状态。
- 链接递交为主，暂不搜索收录。每页保留 `noindex`，直接链接与移动阅读应可用。
- 当前没有正式联系方式，不添加伪造邮箱、二维码或模拟成功的表单；沟通提纲仅供复制，不发送信息。
- 不修改本仓库其他站点、中央发布清单与生产流程来发布 FDE。首次发布需要独立授权和独立站点配置。
- 在仓库根目录运行 `npm run check:fde`，确认静态构建、类型、链接、不收录和案例正文完整性。
