# 秦托邦智能体工坊 · FDE 合作网站

面向通用生态伙伴的独立网站，目标域名 `fde.qintopia.cn`。用于通过链接递交能力与案例，当前全站设置 `noindex, nofollow`。

## 运行与验证

推荐在仓库根目录使用 Node.js 24：

```bash
npm ci
npm run dev
```

开发服务默认在 3000 端口。仓库根目录脚本只转发到 FDE workspace，不修改其他静态站点。

```bash
npm run check:fde
python3 scripts/site/package.py check
python3 -m unittest discover -s scripts/site/tests -v
```

`check:fde` 检查 TypeScript、独立页面、完整案例正文、站内资源及不收录设置，并验证两种构建：

- `npm run build` + `npm start`：标准 Next.js 应用，允许使用服务器运行时；这是默认构建方式。
- `npm run build:static`：当前内容页静态导出至 `sites/fde/out/`，可用于 COS＋CDN。

用户以最终呈现效果为优先，允许使用应用服务器。静态导出是当前代码具备的兼容选项，不是限制 v0 最终方案的硬要求。若后续设计加入确实依赖服务端的功能，应说明需求并相应调整静态检查。`out/`、`.next/`、`node_modules/` 不纳入 Git。

## 内容结构

- `content/site.ts`：首页、服务能力和合作方式，内容与组件分离。
- `content/cases.json`：11 个完整脱敏案例。每篇由结构化段落和列表组成，React 作为文本渲染，不执行原文 HTML。
- `app/`：4 个一级页面和静态生成的案例详情页。
- `components/`：导航、业务流程、案例卡片、筛选搜索和沟通提纲等组件。
- `app/globals.css`：设计 tokens 与样式，已启用 Tailwind CSS，方便 v0 使用模板。
- `public/social-card.svg`：自主绘制的文字分享封面源文件；PNG 为它的栅格版本。

独立案例地址固定为 `/cases/<slug>/`，支持直接打开、刷新和分享。案例完整正文直接包含在导出的 HTML 中，阅读不依赖弹窗或运行客户端脚本。筛选与搜索是客户端增强。

## 本轮首页调整

原方案优先介绍服务过程，读者需要自行推导业务价值。本轮首页改为：

1. 直接说明「让 AI 处理重复工作，让业务协作有据可查」。
2. 用群聊收单到业务系统的链路解释具体应用，同时显示人工异常处理。
3. 呈现订单、数据、模型服务和跨岗位协作四类业务变化，并链接相应案例。
4. 再展示精选项目、交付步骤和合作方式。

2026-10-26 已完成基于 Distyl 设计方法的独立前端实现：暖白与深绿、编辑式大标题、业务连接概念图、四类可切换业务场景、案例与服务说明。首页先建立价值主张，再解释工作变化、项目实践与服务协作。概念图不是产品截图，不代表交付成果。

中文使用 `@fontsource-variable/noto-sans-sc` 的自托管字体资源（SIL OFL），由应用打包和加载，不依赖访客操作系统字体或外部字体 API。动效仅作用于概念图，遵循减少动态效果设置。默认采用标准 Next.js 运行，所有内容预渲染；保留静态导出，两种构建均已验证。没有新增服务端业务接口、数据库、登录或提交表单。详细交接与待补素材见 `docs/design-handoff.md`。

## 对外内容边界

内容来自用户指定的《FDE 服务能力清单框架稿》和《秦托邦智能体工坊客户案例集脱敏版》。案例标题为网页阅读优化，正文保留当前来源含义与四段结构。高校位于首位，酒店位于末位。

服务文案已通用化，保留平台适配、接口开放、数据授权和项目分工条件。没有新增量化收益、客户实名、价格、认证、伙伴等级或项目验收状态。

品牌名称为文字呈现，正式 Logo 与联系渠道待用户提供。合作页可复制真实的沟通提纲，不发送消息或模拟表单成功。下载 PDF、正式配图与商务联系入口未在此代码交接范围内实现，页面不提供无效入口。

## 发布边界

当前是供 v0 继续设计的源代码 PR。FDE 没有进入 `config/site-manifest.json`，也没有修改现有 `Website production`。本轮不部署域名、创建云资源或发布生产。

首次生产发布前，按仓库契约明确扩展站点选择、中央发布范围、独立制品、发布权限、版本 marker、证书与回滚，再完成 COS 读回、CDN 刷新、有效 TLS 和实际内容验证。若未来增加 PDF，不收录的响应头需一并配置。

详细设计交接见根目录 [V0.md](../../V0.md)。
