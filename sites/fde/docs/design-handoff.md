## 参考方式

先打开 Distyl 当前网站，再做视觉判断。它的首页将一个明确的价值主张放在中心，紧接一段交代服务对象和执行方式的说明；主导航把技术、案例与公司信息分开，首屏配有 Canvas 视觉。参考这种表达密度、层级和科技感，不复制它的品牌素材、产品名、客户背书或业务承诺。

本轮已读取首页文字与导航结构；截图采集超时，尚未对其动画细节做验收。v0 应自行查看参考网站在桌面和手机上的实际效果，不把未经观察的动效写成复刻要求。

## FDE 站点要让读者理解的事情

1. 秦托邦帮助企业与生态伙伴，把 AI 接入业务流程和已有系统。
2. 业务价值可以通过订单流转、数据标准化、模型服务治理和跨岗位协作说明。
3. 这些价值有对应的匿名项目案例支撑。
4. 可以按服务模块委托、联合交付，或安排阶段陪跑。

首页文案可继续优化，当前内容稿的标题与分段不是硬性设计要求。优先用简洁主张建立方向，再以真实业务结果和案例建立可信度，不让服务名词成为理解门槛。

## 可以重做与应保留的内容

可重做：首屏排版、区块布局、颜色、字体、图像、Canvas/WebGL、滚动叙事、微交互、卡片样式和文案节奏。以可读性、移动使用、加载体验与键盘操作为基础；动效需支持减少动态效果偏好。

应保留：4 个一级页面、7 项服务能力、11 个完整案例与固定地址、匿名身份、案例事实、技术边界、四段案例叙事、全站暂不收录意图。

不要为了贴近参考而添加未经证实的客户规模、收益数字、专有技术产品、认证或战略伙伴 Logo。科技感应由视觉和解释方式建立。

## 运行与部署选择

- 默认 `npm run build` 生成标准 Next.js 应用，支持应用服务器方案。
- 当前内容站同时支持 `npm run build:static`，输出可放到 COS＋CDN。
- 动效本身不预设部署形态；若引入 SSR、身份登录、实时业务接口等运行时需求，写清功能与运行要求，再选择应用服务器。
- v0 完成设计后，交付源码、可运行预览与验证结果。正式部署独立评估，不直接改变现有主站。
