# 秦托邦 OPC 招募站

目标域名：`opc.qintopia.cn`。

本目录保留给 OPC 招募站的页面与专属资源，当前没有可发布页面。主站继续使用根目录的 `index.html` 和 `mobile.html`，不搬动现有文件。

- 两站各自组织首屏、招募对象、申请条件、FAQ 与申请入口，不设置互相导航。
- 照片、品牌标识、地址等基础资料可以复用；共享文案需核实对两类招募都成立，不直接沿用未经确认的服务承诺。
- 已有图片先从仓库 `images/` 引用；未来打包时把用到的资源完整纳入 OPC 自己的制品，不依赖生活版线上资源的当前版本。无需为本次准备移动主站图片或抽取通用组件。
- 页面、CSS 和脚本的站内路径以 OPC 网站根目录为准；源站 `/opc` 前缀由 CDN 与发布工具处理，不写进浏览器端路径。
- 独立维护标题、描述、canonical 和索引文件；正式页面完成前保持不收录。

本目录目前不在发布清单内，不能使用现有主站工作流直接发布。基础设施状态与首次发布条件见 [准备记录](../../docs/operations/opc-site-preparation.md)。
